# FastApi & Aiogram проект с планировщиком задач Celery/RabbitMQ

## Описание
#### Проект представляет собой telegram бота, который по запросу пользователя предоставляет график `matplotlib` с погодой на сегодня\завтра в выбранном городе. 
`FastApi` выступает в роли отдельного процесса, который:
- Работает с `postgres`
- Записывает пользователей, которые могут пользоваться ботом (с возможностью аналитики в будущем)
    - Возможность пользоваться ботом предоставляется после прохождения аутентификации, реализованная с помощью `redis` `JWT` `access_token` `refresh_token`
- Работает с внешними API для получения погодных данных
  - производит работу с ними с помощью `pandas`

## Особенности 
- Полностью асинхронный проект
- Интерграционные тесты API `pytest-asyncio`
  - Мокирование функций
  - `httpx` `ASGITransport`
  - Отдельная тестовая база данных `postgres`, полностью изолированная от рабочей
  - Возможность запускать тесты в `docker` контейнере
- Планировщик задач `celery`, реализующий рассылку погоды в заданное время с учётом часового пояса
- `logger`
- Миграции для основной и тестовой базы данных `alembic`
- Запуск сразу шести полностью настроенных контейнеров с помощью `docker-compose`
